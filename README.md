# 医院三基考试管理系统

面向医院"三基"（基础理论、基本知识、基本技能）培训考核的全流程管理系统。零外部依赖，Node.js 内置模块实现。

## 业务流程

```
护理部发布考试（选择岗位 + 科室范围 + 时间/合格线/学分）
        │
        ▼
考生按岗位进入不同题库 ──► 在线答题（倒计时、客观题自动判分）
护士 / 医生 / 技师            │
        │                     ▼
        │            主观题（简答/论述）→ 科室老师批阅打分（仅本岗位试卷）
        │                     │
        ▼                     ▼
成绩自动归入个人培训档案（均分/合格率/累计学分）
        │
        ▼
护理部"结考" → 未交卷者自动登记【缺考】→ 缺考/不合格自动进入【补考名单】
        │
        ▼
护理部一键创建补考并通知到人

院级管理员：只看全院汇总指标与薄弱知识点聚合（看不到题库、个人明细、批阅入口）
```

## 快速开始

```bash
node seed.js          # 初始化/重置演示数据（可选，已附带 data/db.json）
node server.js        # 启动，默认 http://localhost:3000 （PORT=xxxx 可改端口）
```

## 题型与判分

- **客观题**（系统自动判分）：单选、多选（全对才得分）、判断、填空题（按空平均给分，忽略标点空格差异）
- **主观题**（科室老师按参考要点打分，0~满分校验，不可越岗位批阅）：简答、论述
- 每套卷满分 100 分（5+5+10+5+10+25+40），合格线与学分由护理部按场设定

## 技术说明

- 后端：`server.js`，Node 内置 http/fs/crypto，JSON 文件持久化（`data/db.json`，临时文件+rename 原子写入），内存 token 会话
- 前端：`public/` 原生 HTML/CSS/JS 单页应用，无构建步骤
- 数据种子：`seed.js`（可随时重置演示数据）
- 接口测试：`./test-api.sh`（自动重建数据、重启服务，61 项断言覆盖权限边界/批阅/缺考/补考/档案/院级隔离）
