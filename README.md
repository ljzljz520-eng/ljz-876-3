# 医院三基考试管理系统

面向医院护理部、科室老师、医生/护士/技师考生与院级管理员的「三基（基本理论、基本知识、基本技能）」考试闭环管理系统。

## 业务流程

```
护理部维护分岗位题库 ──► 面向科室发布考试（按岗位随机抽题组卷、自动生成考生名册）
        │
        ├─ 考生（医生/护士/技师）进入【本岗位】考试 ──► 在线作答 ──► 交卷
        │        ├─ 客观题（单选/多选/判断）：系统自动判分
        │        └─ 主观题（简答）：科室老师批阅打分 + 批阅意见
        │
        ├─ 考试截止：未交卷者自动判定【缺考】→ 进入补考名单
        ├─ 批阅完成：成绩低于合格线 → 进入补考名单（原因=不合格）
        │            成绩自动归档至个人【培训档案】
        │
        ├─ 科室老师：批阅本科室主观题、查看本科室汇总
        ├─ 护理部：通知补考 / 安排补考专场 / 豁免，闭环跟踪
        └─ 院级管理员：仅看全院汇总指标与薄弱知识点（不可访问题库与个人明细）
```

## 角色与权限（RBAC）

| 角色 | 账号示例 | 能力边界 |
|---|---|---|
| 护理部管理员 `nursing_admin` | `nursing` | 维护题库/知识点与人员科室、按科室+岗位发布考试、组卷、截止考试、安排/豁免补考、查看全部汇总与薄弱点 |
| 科室老师 `dept_teacher` | `teacher_xnk` | **仅本科室**：批阅主观题、查看本科室汇总与档案、通知本科室补考人员 |
| 考生 `examinee` | `n1` `d1` `t1` | 只能看到本岗位考试与题库（不返回标准答案）、在线考试、查看本人成绩与培训档案 |
| 院级管理员 `hospital_admin` | `hospital` | 仅全院汇总驾驶舱、薄弱知识点、补考跟踪；题库/发布/批阅/明细接口一律 403 |

## 核心功能

- **分岗位题库隔离**：医生、护士、技师三套独立题库；题库维护知识点标签，作为薄弱分析维度
- **随机组卷**：发布时按题型数量/分值从对应岗位题库随机抽题，生成**题目快照**（题目后续修改不影响历史试卷）
- **自动名册**：所选科室中同岗位在职考生自动入册；开考前校验时间窗、名册、重复作答
- **自动判分**：单选/判断精确匹配，多选需选项集合完全一致；考试窗口截止自动交卷保护
- **缺考判定（双触发）**：到达截止时间后，护理部手动截止或任意接口访问触发惰性扫描（`sweepDueExams`），未交卷者 `assigned → absent` 并写入 `makeup_list(reason=absent)`
- **主观题批阅**：科室老师按题在 0~满分区间打分（可写逐题意见与总评）；自动算总分、判定合格、归档培训档案；**不合格自动入补考名单**；支持更正批阅并联动补考状态
- **补考闭环**：`待处理 → 已通知 → 已安排（补考专场）→ 已完成/豁免`；护理部可将人员加入岗位匹配的补考专场名册
- **培训档案**：考生与有权限的管理者可查看历次考试成绩（客观分+主观分）、合格情况与平均分
- **薄弱知识点分析**：按知识点聚合已批阅答卷的得分率（掌握率、人均失分），支持按岗位/科室/考试过滤；院级与护理部据此安排专项培训

## 技术栈

- 后端：Node.js + Express，数据库 better-sqlite3（WAL 模式，零外部服务），数据文件 `data/sanji.db`
- 认证：scrypt 密码哈希 + HMAC-SHA256 签名 Bearer Token（8 小时有效）
- 前端：原生 HTML/CSS/JavaScript 单页应用，按角色动态渲染工作台，纯 CSS 条形图
- 测试：`node:test` 内置测试框架，临时库端到端覆盖 13 个关键场景

## 快速开始

```bash
npm install
npm run seed     # 初始化演示数据（可选，--force 重置）
npm start        # http://localhost:3000
npm test         # 运行端到端自动化测试
```

首次启动若无任何用户，会自动创建护理部账号 `nursing / admin123`。

## 主要 API

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/login` | 登录获取 token |
| GET/POST | `/api/questions` `/api/knowledge-points` | 题库与知识点（护理部维护；考生仅本岗位且无答案；院级 403） |
| POST | `/api/exams` | 发布考试并随机组卷（护理部） |
| GET | `/api/exams` | 按角色范围列考试（考生仅本岗位名册） |
| POST | `/api/exams/:id/start` `/paper` `/submit` | 考生开考/取卷/交卷 |
| GET | `/api/exams/:id/grading/pending` `/api/attempts/:id` `POST /api/attempts/:id/grade` | 科室老师批阅主观题 |
| GET | `/api/exams/:id/summary` | 考试汇总（科室老师自动限本科室） |
| GET | `/api/makeup` `POST /api/makeup/:id/status` `/arrange` | 补考名单与闭环 |
| GET | `/api/training-records/:userId` | 培训档案（权限校验） |
| GET | `/api/admin/overview` | 院级汇总驾驶舱（仅院级） |
| GET | `/api/analytics/weak-points` | 薄弱知识点分析 |

## 数据模型

`departments`、`users`、`knowledge_points`、`questions`、`exams`、`exam_depts`、`exam_roster`、`exam_questions`(试卷快照)、`attempts`、`answers`、`makeup_list`、`training_records`。
